# CB Diner: Upwork portfolio entry

## Project title (62 / 70 characters)

CB Diner – Restaurant QR Ordering PWA with Live Kitchen Screen

## My role

Product designer & full-stack developer: UX, visual design, front end, back end, real-time kitchen screen and PWA (concept project).

## Description (453 / 600 characters)

A table-ordering web app for an upscale New York steakhouse: guests scan the QR on their table and order from their phone.
• QR menu with table number, search, dietary marks
• Cart, kitchen notes, order to Supabase or WhatsApp
• Live kitchen board: Realtime, bell alert, timers
• Admin: sold-out switch, prices, photo upload, table QR codes
• Installable PWA that works offline
Next.js 15, Supabase, Tailwind. Concept project – all content is demo data.

## Skills (5)

2. React
3. TypeScript
4. Supabase
5. Progressive Web App
